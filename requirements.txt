# BQT-MDQW - pinned dependency set

# Versions marked "tested" are the versions this prototype was actually built and
# executed against on the development machine. Lower bounds are chosen so that a
# future install does not silently pull in a breaking API change; the upper bounds
# only guard against known incompatible major releases.
#
# IMPORTANT (Qiskit 2.x): the legacy `c_if` classical-conditioning API was removed
# in Qiskit 2.0. This project uses `QuantumCircuit.if_test(...)` instead.
# See: https://quantum.cloud.ibm.com/docs/en/guides/qiskit-2.0

# --- Quantum computing ---------------------------------------------------------
qiskit>=2.0,<3.0                 # tested with 2.5.2
qiskit-aer>=0.15,<1.0            # tested with 0.17.2 (includes AerSimulator + NoiseModel)

# `QuantumCircuit.draw("mpl")` raises MissingOptionalLibraryError, which is why
# the demo notebook's circuit diagrams need it.
pylatexenc>=2.10,<4.0            # tested with 2.11
